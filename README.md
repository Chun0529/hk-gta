# 香港GTA · 去香港狂飆

瀏覽器入面行得、揸得的香港夜城小品。中環天星碼頭走到灣仔，接幾個短任務，解鎖一堆稱號。

本作所有品牌皆為虛構諧仿，與 Rockstar Games 無關。

## 點玩

```bash
npm install
npm run dev
```

打開終端機顯示的網址。存檔喺呢個瀏覽器入面，換電腦就會冇。

## 操作

- `W A S D` 移動，`Q` / `R` 或者滑鼠轉向
- `Shift` 衝刺，`E` 互動，`F` 上落的士或叮叮
- `H` 喇叭，空白鍵係的士手煞
- `M` 地圖，`T` 手機，`Esc` 暫停
- 手機左邊搖桿行，右邊拖視角

## 稱號

角色開局稱號：的士之王、綠van車神、廟街話事人、天星大副。

其餘靠行為解鎖，可以喺稱號頁裝備一個：

- 初來報到、海傍散步、菠蘿包續命、茶記熟客
- 絲襪奶茶迷、奶茶品鑑師
- 蛋撻飛人、霓虹收藏家、叮叮常客、港鐵通勤族
- 蘭桂坊熟客、維港打卡、通宵達人、落雨都要出街
- 喇叭交響曲、避車之神、紅燈哲學家、的士夜更
- 慳家、豪客、打工仔、街頭傳說

新遊戲會重置街道進度，已經解鎖的稱號會保留。
